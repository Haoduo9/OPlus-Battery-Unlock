# Realme GT6 (RMX3800) / OPlus 电池放电截止电压与深放惩罚优化模块

适用于 **真我 GT6 (RMX3800)** 以及搭载 `oplus_chg_v2` / `oplus-votable` 机制的 ColorOS 14 / 15 / 16 等机型。

---

## 模块功能与原理

1. **放电截止电压优化**：
   - 默认策略中，系统底层将关机截止电压门限设定在 3300mV。
   - 本模块通过欧加内核内置的调试投票接口 (`/proc/oplus-votable/`)，将关机与统计截止电压统一调整至 3100mV。
   - 释放底部部分冗余电量，同时保持充裕的安全电压余量。

2. **深放电惩罚计数重置**：
   - 开机自动重置 `deep_dischg_counts` 异常计数，防止系统内核算法对全充容量进行二次加权扣减。

3. **纯用户态无损**：
   - 本模块不修改任何系统只读分区（system / vendor / odm 等）。
   - 停用或卸载模块后重启设备，内核即刻恢复默认设定。

---

## 使用与验证

- **安装**：通过 Magisk 或 KernelSU 本地刷入并重启。
- **验证**：打开终端或通过 adb 执行：
  ```bash
  su -c cat /sys/class/oplus_chg/battery/vbat_uv
  ```
  若输出为 `3100` 即表明优化参数已生效。
